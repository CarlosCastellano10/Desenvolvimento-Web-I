4. Listas em HTML

As listas em HTML permitem organizar informações de forma estruturada. Existem três tipos principais de listas: listas ordenadas, listas não ordenadas e listas de definição

Exemplo - Lista não ordenada:

  • Pastel
    • Massa
    • Proteína (frango, carne, palmito)
    • Molho vinagrete (opcional)
  • Crepe
    • Massa preparada
    • Proteína (presunto, queijo, nutella, doce de leite)
    • Cobertura (doces: brigadeiro, nutella, etc)
  • Bolo
    • Massa do bolo
    • Recheio (morango, chocolate, brigadeiro, doce de leite)
    • Cobertura (doces: brigadeiro, nutella, chantilly)

    • Exemplo - Lista ordenada:

    1. Santos
    2. Coritiba
    3. Athletico Paranaense
    4. Paraná Clube
    5. Rio Branco

    Exemplo - Lista de definição

    HTML
    Linguagem de marcação utilizada para estruturar conteúdo na web
    CSS
    Linguagem de estilo utilizada para definir a aparência visual de páginas na web
    JavaScript
    Linguagem de programação utilizada para interatividade

    5. Links em HTML

    A tag <a> cria links com outros documentos ou âncoras

    Exemplo - Link externo:

    <a> href="https://www.google.com.br" target="_blank">Acesse o Google</a>

    Acesse o Google

    Exemplo - Link página interna:

    <a> href="teste.html" target="_blank">Acesse a página 2</a>

    Acesse a página 2

    Exemplo - Âncora

    <a href="#nome">Acesso ao item </a>

    Acesse o inicio da pagina

    A tag <img> é utilizada para inserir imagens em uma página web.

    8. Tabelas em HTML

    A tag <table> é usada para criar tabelas no HTML

    <tr> - Cria uma linha na tabela

    <th> - Cria uma célula de cabeçalho na tabela

    <td> - Cria uma coluna de dados na tabela

    Exemplo simples

    Nome Idade Cidade
    João 25 São Paulo
    Maria 30 Rio de Janeiro
    Carlos 28 Belo Horizonte
